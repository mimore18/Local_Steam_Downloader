# Local Steam Downloader

Кроссплатформенная утилита для скачивания коллекций и отдельных модов Steam Workshop.

- Windows 10/11 и Linux.
- CLI и простое окно на Tkinter.
- Метаданные — через Steam Web API, файлы — через официальный SteamCMD.
- Выборочная загрузка, resume по манифесту, человекочитаемые имена папок.
- Оба режима входа: анонимный и под аккаунтом Steam.

> Скачивание возможно только для контента, к которому у аккаунта есть доступ.
> Проект не обходит приватность, платные моды и ограничения Steam.

## Установка

Требуется Python 3.11+. SteamCMD устанавливать вручную не обязательно: при первом
скачивании программа сама загрузит официальный архив Valve в папку `steamcmd/`
рядом с проектом (или в пользовательский data-dir для установленного пакета).

```bash
python -m pip install -e ".[dev]"
python -m pytest -q
```

## Использование

Из корня проекта:

```bash
# интерактивный мастер: тип → ссылка → список модов → y/n
python3 run_cli.py

# обычный CLI со всеми флагами
python3 run_cli.py "https://steamcommunity.com/sharedfiles/filedetails/?id=123456789" --list
python3 run_cli.py 123456789 --type collection --login USER

# графический интерфейс
python3 run_gui.py
```

Или через модуль/установленную команду:

```bash
# посмотреть состав коллекции
steam-workshop-dl "https://steamcommunity.com/sharedfiles/filedetails/?id=123456789" --list

# скачать коллекцию анонимно
steam-workshop-dl 123456789 --type collection -o ~/Downloads/workshop --anonymous

# скачать один мод
steam-workshop-dl 123456789 --type mod -o ~/Downloads/workshop

# графический интерфейс
steam-workshop-dl --gui
```

Полный список флагов: `steam-workshop-dl --help`.

### SteamCMD

Если SteamCMD не найден, он автоматически скачивается с официального сервера Valve
и распаковывается:

- в `<корень проекта>/steamcmd/` при запуске из исходников;
- в `~/.local/share/steam-workshop-dl/steamcmd` (Linux) или
  `%LOCALAPPDATA%\steam-workshop-dl\steamcmd` (Windows) для установленного пакета.

Переопределить папку: `STEAM_WORKSHOP_STEAMCMD_DIR=/путь/к/steamcmd`.
Отключить автозагрузку: `--no-steamcmd-bootstrap` или снять галочку в GUI.
Свой путь задаётся через `--steamcmd /путь/к/steamcmd.sh`; неверный путь
не запускает загрузку в другое место, а показывает ошибку.

### Интерактивный CLI

`python3 run_cli.py` без аргументов показывает название и версию, спрашивает тип
(коллекция или мод), ссылку и папку, выводит дерево модов и просит подтверждение
`y/n`. Пустой ответ для типа — коллекция, для папки — путь по умолчанию;
подтверждение по умолчанию — «нет». Вход в мастере анонимный, для аккаунта
запускайте с аргументами: `python3 run_cli.py <ID> --login USER`.

### Графический интерфейс

1. Выберите тип цели: «Коллекция» или «Мод».
2. Вставьте ссылку или ID, укажите папку (SteamCMD можно оставить пустым — будет найден автоматически).
3. При необходимости включите вход под аккаунтом Steam: логин указывается в окне, пароль и код Steam Guard — в отдельных диалогах.
4. Нажмите «Показать список», снимите галочки с ненужных модов.
5. Нажмите «Скачать выбранное». Прогресс, статусы и лог отображаются в окне.
6. «Повторить ошибки» перезапускает только неудачные и отменённые загрузки.
7. Поле «Поиск» фильтрует список по названию или ID; выбор галочек при фильтрации сохраняется.
8. Параметры: докачка (resume), проверка файлов (validate) и упаковка в ZIP.

## Статус

Работают метаданные, разбор коллекций, CLI и GUI, выборочная загрузка через SteamCMD,
resume по манифесту, анонимный вход и вход под аккаунтом со Steam Guard.
Тип цели определяется через `GetCollectionDetails`, потому что `filetype` в
`GetPublishedFileDetails` бывает `0` даже у настоящих коллекций. Проверено на живых
коллекциях и одиночных модах, включая загрузку через GUI.
